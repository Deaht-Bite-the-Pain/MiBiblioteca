# Desafío 3 – Mi Biblioteca

El proyecto ya está completo y compila. Solo falta conectar tu Firebase.

1. En https://console.firebase.google.com crea un proyecto.
2. Agrega una app Android con el paquete `com.example.desafio03`.
3. Descarga `google-services.json` y reemplaza el archivo de `app/google-services.json` (el actual es un placeholder).
4. En Authentication > Sign-in method, habilita **Correo electrónico/contraseña**.
5. En Android Studio: File > Open > carpeta `Desafio03`, espera el Sync y ejecuta (Run).
